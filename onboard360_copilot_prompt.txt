## 2) RBAC with Casbin (pycasbin)

Create `server/app/casbin/model.conf`:

```
[request_definition]
r = sub, obj, act

[policy_definition]
p = sub, obj, act

[role_definition]
g = _, _

[policy_effect]
e = some(where (p.eft == allow))

[matchers]
m = g(r.sub, p.sub) && r.obj == p.obj && r.act == p.act
```

Create `server/app/casbin/policy.csv` (examples):

```
p, partner_user, partner:dashboard, read
p, partner_user, partner:raise_intake, write
p, partner_user, partner:track, read
p, partner_user, partner:my_actions, read

p, onboarding_team_member, otm:dashboard, read
p, onboarding_team_member, otm:sprint, read
p, onboarding_team_member, otm:my_actions, read
p, onboarding_team_member, otm:team_actions, read

p, icmp_leadership, lead:dashboard, read
p, icmp_leadership, lead:my_actions, read

p, product_owner, po:dashboard, read
p, product_owner, po:sprint, read
p, product_owner, po:my_actions, read
p, product_owner, po:team_actions, read
```

Bind users to roles in app logic (from `users.json`) or extend with `g, username, role` entries.

Implement a **FastAPI dependency** `authorize(obj: str, act: str)` that:
- reads the current user’s role from the JWT
- calls `enforcer.enforce(role, obj, act)`
- raises `HTTPException(403)` on deny

Use **route‑local permissions** like `obj='partner:dashboard'`, `act='read'`.

## 4) Backend — API Contracts & Implementations (FastAPI)

### 4.1 Auth & Session

**Endpoints**
- `POST /api/auth/login` `{ username, password } -> { user, token }`
- `POST /api/auth/logout` clears cookie
- `GET  /api/me` → current user info (from jwt)

**Logic**
- Verify username/password against static `users.json` (bcrypt)
- Issue JWT (HS256) with claims: `sub=user.id`, `uname`, `role`, `exp`
- Set JWT in **httpOnly cookie**; also return token in body for dev
- CSRF: for any **state‑changing** method (POST/PUT/DELETE), require header `x-csrf` == value from cookie `csrf_token`

### 4.2 Config
- `GET /api/config -> { dataSource, featureFlagsPerRole }`
  - Read from `config/features.json` and `.env` (`DATA_SOURCE`)

### 4.3 Partner (Protected by RBAC)
- `GET  /api/partner/dashboard -> { draft, submitted, completed, list: [Intake] }`
- `POST /api/partner/intakes -> Intake` (create; accepts partial from chatbot form)
- `GET  /api/partner/intakes -> [Intake]` (for Track my Intakes)
- `GET  /api/partner/action-items -> [ActionItem]`

### 4.4 Onboarding Team Member (OTM)
- `GET /api/otm/dashboard -> { totals, tasks, pendingPartnerResponses, myPending, teamPending }`
- `GET /api/otm/sprint -> [Feature]`
- `GET /api/otm/my-action-items -> [ActionItem]`
- `GET /api/otm/team-action-items -> [ActionItem]`

### 4.5 Leadership
- `GET /api/lead/dashboard -> { charts: { intakesByStatus, intakesByLob, intakesByLobStatus, ongoingFeatures, featuresInRisk, delayedFeatures, trends } }`
- `GET /api/lead/my-action-items -> [ActionItem]`

### 4.6 Product Owner / Scrum Master
- `GET /api/po/dashboard -> { charts: ... }` (scoped by team)
- `GET /api/po/sprint -> [Feature]`
- `GET /api/po/my-action-items -> [ActionItem]`
- `GET /api/po/team-action-items -> [ActionItem]`

### 4.7 Chatbot
- `POST /api/chat/send { threadId?, message } -> { threadId, messages:[...] }`
- `GET  /api/chat/history?threadId=...`
- `POST /api/chat/upload` (multipart) -> `{ fileId, name, size }`
- Mock behavior: echo + simple form template generation; store history per user in memory with optional disk persistence (`data/chat/threads.json`)

**Sample: `authorize_dependency`**

```py
def authorize_dependency(obj: str, act: str):
    def _dep(user: User = Depends(get_current_user), enforcer: Enforcer = Depends(get_enforcer)):
        if not enforcer.enforce(user.role, obj, act):
            raise HTTPException(status_code=403, detail="Forbidden")
        return True
    return _dep
```

**Sample: Auth route snippets**

```py
@router.post("/auth/login", response_model=LoginResponse)
def login(payload: LoginRequest, response: Response):
    user = user_repo.get_by_username(payload.username)
    if not user or not verify_password(payload.password, user.hashed_password):
        raise HTTPException(401, "Invalid credentials")
    token, csrf = issue_tokens(user)
    set_session_cookies(response, token, csrf)
    return {"user": public_user(user), "token": token}
```

**CSRF enforcement example (for state‑changing routes)**

```py
def require_csrf(request: Request):
    csrf_cookie = request.cookies.get("csrf_token")
    csrf_header = request.headers.get("x-csrf")
    if not csrf_cookie or csrf_cookie != csrf_header:
        raise HTTPException(403, "CSRF check failed")
```

Attach via `dependencies=[Depends(require_csrf)]` on POST/PUT/DELETE routes.

**File uploads** saved to `static/uploads/` with UUID fileId; store metadata in repo.
